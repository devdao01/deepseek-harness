# Agent Note: 浏览器操作 URL 保留应用基地址

Status: implemented

[English](2026-09-23-browser-action-app-base.md) | 中文

## Problem

子路径前端发布 `__DSH_APP_BASE__`，但原生文件操作、应用发现／图标以及会话 ZIP 下载可能访问域名根目录并收到 404 响应。

## Decision

三个消费方根据绝对应用基地址解析浏览器 URL，采用与文件上传相同的移除开头斜杠和补齐末尾斜杠规则。未设置基地址时，保留现有的源地址行为。交付状态键仍是会话坐标；只有发出的请求重新定位。导出预检和浏览器下载共用解析后的 URL。

## Alternatives considered

**共享插件导出。** 导入另一个功能插件的运行时辅助函数会违反客户端分层。新增工具包会将这次局部 URL 修正扩大为包和构建变更。

**域名根目录代理路由。** 根目录别名会耦合部署，使挂载在不同前缀下的应用争用相同路由。

## Consequences

辅助函数保留在各自包内，代价是少量重复的 URL 规范化代码。聚焦的浏览器测试覆盖根目录部署、带或不带末尾斜杠的前缀基地址，以及元数据、打开／显示文件、应用图标与启动、导出预检／下载 URL。此变更不改变会话事件或模型可见输出。
